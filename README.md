\# Low-Noise High-Speed DAQ Analog Front-End



Design and validation of a low-noise, high-speed analog front-end for data acquisition systems.



\## Objectives



\- Design a low-noise analog front-end (AFE)

\- Perform circuit simulation in LTspice (AC, transient, noise)

\- Develop a high-speed PCB in Altium

\- Validate system performance through measurements



\## Architecture



Input Signal → Analog Front-End → Anti-Aliasing Filter → ADC Driver → DAQ



\## Project Structure



\- `calculations/` – Design equations and noise budget

\- `ltspice/` – Circuit simulations

\- `altium/` – PCB design files

\- `docs/` – Diagrams and design notes

\- `measurements/` – Experimental validation
